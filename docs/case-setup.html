Case directory structure

Every OpenFOAM case — whether using the stock solver or simpleFoamExtracted — follows the same three-directory layout. The solver discovers all settings by walking this tree at startup; nothing is hard-coded inside the binary.

myCase/
├── 0/ # initial & boundary conditions (time = 0)
│ ├── U # velocity field
│ ├── p # kinematic pressure (p/ρ, units m²/s²)
│ ├── k # turbulent kinetic energy
│ ├── epsilon # turbulent dissipation rate (k-ε)
│ └── nuTilda # modified viscosity (S-A)
├── constant/ # time-invariant case data
│ ├── physicalProperties # kinematic viscosity ν
│ ├── turbulenceProperties # turbulence model selector
│ └── polyMesh/ # mesh (created by blockMesh)
│ ├── points
│ ├── faces
│ ├── owner
│ ├── neighbour
│ └── boundary
└── system/ # solver control files
├── controlDict # run control, time, I/O
├── fvSchemes # numerical discretisation schemes
├── fvSolution # linear solvers & relaxation
└── blockMeshDict # mesh geometry definition
The three top-level directories are mandatory. OpenFOAM refuses to start if system/controlDict, constant/physicalProperties, or constant/turbulenceProperties are missing.

Required files explained

system/controlDict

Master run-control dictionary. Tells the solver how long to run, how often to write results, and which optional function objects to activate (residual monitors, sampling, probes).

KeyTypical valueMeaning
applicationsimpleFoamIdentifies the solver (informational only)
startFromstartTimeStart from the time named in startTime
startTime0Initial time directory to read
stopAtendTimeStop when endTime is reached
endTime500Number of SIMPLE iterations
deltaT1Pseudo-time step (always 1 for steady SIMPLE)
writeControltimeStepWrite every N iterations
writeInterval50N iterations between writes
runTimeModifiabletrueRe-read dicts each iteration (live editing)

Keep the functions{} sub-dictionary empty (or remove it entirely) when running simpleFoamExtracted, because the vendored build omits the sampling and streamlines libraries — any includeFunc or streamlines entry will cause a fatal error at startup.

system/fvSolution

Configures the linear algebra solvers for each field and the SIMPLE algorithm's under-relaxation factors. This file has the largest impact on convergence speed and stability.

Sub-dictionaryPurpose
solvers{}One entry per field: which iterative solver + preconditioner to use
SIMPLE{}Convergence tolerance and residual-control switches
relaxationFactors{}Under-relaxation for fields and equations

Recommended solver choices: GAMG (geometric-algebraic multi-grid) for pressure because the elliptic pressure equation benefits most from multigrid; smoothSolver with GaussSeidel for the convection-dominated momentum and turbulence equations.

system/fvSchemes

Selects the numerical approximation scheme for every spatial and temporal operator that appears in the governing equations.

Sub-dictionaryOperators covered
ddtSchemesTime derivative ∂/∂t (use steadyState for SIMPLE)
gradSchemesGradient ∇ — Gauss linear is standard
divSchemesDivergence / convection — linearUpwind for U, upwind for k/ε
laplacianSchemesDiffusion — Gauss linear corrected
interpolationSchemesFace interpolation — linear
snGradSchemesSurface-normal gradient — corrected

system/blockMeshDict

Defines the mesh using structured hexahedral blocks. The workflow is: declare vertices in 3-D space, connect them into blocks specifying the cell count in each direction and a grading ratio, then name the boundary patches. blockMesh reads this file and writes the resulting constant/polyMesh/ directory.

Grading lets you cluster cells near walls (small y⁺) without exploding the total cell count. A grading of 4 means the last cell is 4× the size of the first cell along that direction.

constant/turbulenceProperties

Selects the turbulence modelling approach. The two top-level keys are simulationType (RAS, LES, or laminar) and the nested model dictionary.

Common choices for RANS:

ModelRequired fields in 0/Notes
kEpsilonk, epsilonRobust, good for free shear flows
kOmegaSSTk, omegaBetter near walls, adverse pressure gradients
SpalartAllmarasnuTildaOne equation, low overhead

constant/physicalProperties

Specifies the fluid's physical properties. For incompressible flow the only required entry is the kinematic viscosity nu (m²/s). The viscosity model type is also declared here — Newtonian for a constant-viscosity fluid.

Note: older OpenFOAM versions used constant/transportProperties with the key nu directly. OpenFOAM 9+ renamed the file to physicalProperties and added the viscosityModel wrapper.

Example: simple channel flow

A 2-D plane channel, 10 m long × 1 m tall, driven by a fixed inlet velocity of 1 m/s, Reynolds number ≈ 10 000 using k-ε turbulence.

system/blockMeshDict

FoamFile { version 2.0; format ascii; class dictionary; object blockMeshDict; }

scale   1;

vertices
(
    (  0   0  0 )   // 0
    ( 10   0  0 )   // 1
    ( 10   1  0 )   // 2
    (  0   1  0 )   // 3
    (  0   0  0.1 ) // 4
    ( 10   0  0.1 ) // 5
    ( 10   1  0.1 ) // 6
    (  0   1  0.1 ) // 7
);

blocks
(
    // hex (v0 v1 v2 v3 v4 v5 v6 v7) (nx ny nz) simpleGrading (gx gy gz)
    hex (0 1 2 3 4 5 6 7) (200 40 1) simpleGrading (1 4 1)
    //                                                   ^-- cluster near bottom wall
);

edges ();

boundary
(
    inlet
    {
        type patch;
        faces ( (0 4 7 3) );
    }
    outlet
    {
        type patch;
        faces ( (1 2 6 5) );
    }
    bottomWall
    {
        type wall;
        faces ( (0 1 5 4) );
    }
    topWall
    {
        type wall;
        faces ( (3 7 6 2) );
    }
    frontAndBack
    {
        type empty;                 // 2-D: no flux in z-direction
        faces ( (0 3 2 1) (4 5 6 7) );
    }
);

system/controlDict

FoamFile { version 2.0; format ascii; class dictionary; object controlDict; }

application     simpleFoam;

startFrom       startTime;
startTime       0;
stopAt          endTime;
endTime         500;
deltaT          1;

writeControl    timeStep;
writeInterval   50;
purgeWrite      3;               // keep only last 3 time directories

runTimeModifiable true;

functions {}                     // keep empty — sampling libs not vendored

system/fvSchemes

FoamFile { version 2.0; format ascii; class dictionary; object fvSchemes; }

ddtSchemes      { default steadyState; }

gradSchemes
{
    default         Gauss linear;
    grad(U)         cellLimited Gauss linear 1;
}

divSchemes
{
    default         none;
    div(phi,U)      bounded Gauss linearUpwind grad(U);
    div(phi,k)      bounded Gauss upwind;
    div(phi,epsilon) bounded Gauss upwind;
    div((nuEff*dev(T(grad(U))))) Gauss linear;
}

laplacianSchemes { default Gauss linear corrected; }

interpolationSchemes { default linear; }

snGradSchemes   { default corrected; }

fluxRequired    { default no; p ; }

system/fvSolution

FoamFile { version 2.0; format ascii; class dictionary; object fvSolution; }

solvers
{
    p
    {
        solver          GAMG;
        smoother        GaussSeidel;
        tolerance       1e-6;
        relTol          0.1;
    }

    U
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-8;
        relTol          0.1;
        nSweeps         1;
    }

    k
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-8;
        relTol          0.1;
        nSweeps         1;
    }

    epsilon
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-8;
        relTol          0.1;
        nSweeps         1;
    }
}

SIMPLE
{
    nNonOrthogonalCorrectors 0;
    consistent      yes;         // SIMPLEC variant — faster convergence

    residualControl
    {
        p               1e-4;
        U               1e-4;
        k               1e-4;
        epsilon         1e-4;
    }
}

relaxationFactors
{
    fields  { p 0.3; }
    equations
    {
        U       0.7;
        k       0.7;
        epsilon 0.7;
    }
}

constant/physicalProperties

FoamFile { version 2.0; format ascii; class dictionary; object physicalProperties; }

viscosityModel  Newtonian;

nu              1e-4;            // kinematic viscosity [m^2/s]
                                 // Re = U*H/nu = 1*1/1e-4 = 10 000

constant/turbulenceProperties

FoamFile { version 2.0; format ascii; class dictionary; object turbulenceProperties; }

simulationType  RAS;

RAS
{
    RASModel        kEpsilon;
    turbulence      on;
    printCoeffs     on;
}

0/U — velocity initial & boundary conditions

FoamFile { version 2.0; format ascii; class volVectorField; object U; }

dimensions      [0 1 -1 0 0 0 0];   // m/s

internalField   uniform (1 0 0);

boundaryField
{
    inlet       { type fixedValue;      value uniform (1 0 0); }
    outlet      { type zeroGradient; }
    bottomWall  { type noSlip; }
    topWall     { type noSlip; }
    frontAndBack { type empty; }
}

0/p — pressure

FoamFile { version 2.0; format ascii; class volScalarField; object p; }

dimensions      [0 2 -2 0 0 0 0];   // m^2/s^2 (kinematic)

internalField   uniform 0;

boundaryField
{
    inlet       { type zeroGradient; }
    outlet      { type fixedValue;  value uniform 0; }
    bottomWall  { type zeroGradient; }
    topWall     { type zeroGradient; }
    frontAndBack { type empty; }
}

0/k — turbulent kinetic energy

FoamFile { version 2.0; format ascii; class volScalarField; object k; }

dimensions      [0 2 -2 0 0 0 0];

// k = 1.5*(I*U)^2,  I = 0.05 (5% turbulence intensity)
internalField   uniform 3.75e-3;

boundaryField
{
    inlet       { type turbulentIntensityKineticEnergyInlet;
                  intensity 0.05; value uniform 3.75e-3; }
    outlet      { type zeroGradient; }
    bottomWall  { type kqRWallFunction; value uniform 3.75e-3; }
    topWall     { type kqRWallFunction; value uniform 3.75e-3; }
    frontAndBack { type empty; }
}

0/epsilon — turbulent dissipation

FoamFile { version 2.0; format ascii; class volScalarField; object epsilon; }

dimensions      [0 2 -3 0 0 0 0];

// epsilon = Cmu^0.75 * k^1.5 / L,  L = 0.07*H = 0.07
internalField   uniform 7.18e-4;

boundaryField
{
    inlet       { type turbulentMixingLengthDissipationRateInlet;
                  mixingLength 0.07; value uniform 7.18e-4; }
    outlet      { type zeroGradient; }
    bottomWall  { type epsilonWallFunction; value uniform 7.18e-4; }
    topWall     { type epsilonWallFunction; value uniform 7.18e-4; }
    frontAndBack { type empty; }
}

Key parameters

Under-relaxation factors

Under-relaxation damps updates between iterations to prevent divergence of the non-linear system. Lower values = more stable but slower convergence.

Field / equationTypical αNotes
p (field)0.3Pressure needs heavy damping — SIMPLE's weakest coupling
U (equation)0.7Standard; reduce to 0.5 if diverging
k (equation)0.7Same as U
epsilon (equation)0.7Can be reduced to 0.5 for stiff problems
SIMPLEC p0.9SIMPLEC allows higher p relaxation
Rule of thumb: α_U + α_p ≈ 1.0. Increase both by 0.1 once residuals enter the drop phase to speed up final convergence.

Linear solvers

SolverBest forKey settings
GAMGPressure (p) — elliptic, smooth error modessmoother GaussSeidel, relTol 0.1
smoothSolverU, k, epsilon — convection dominatedsmoother GaussSeidel, nSweeps 1
PCGSymmetric systems (p on simple meshes)preconditioner DIC
PBiCGStabAsymmetric systems (U)preconditioner DILU

The relTol key sets the relative (inner-iteration) tolerance. Setting it to 0 forces the solver to reach the absolute tolerance each SIMPLE step — expensive but useful for debugging convergence issues.

Convergence criteria

SIMPLE/residualControl defines the outer-loop stopping criterion. The solver checks the initial residual of each field reported by the linear solver (not the field change). Typical targets:

FieldEngineering accuracyHigh accuracy
p1e-31e-5
U1e-41e-6
k, epsilon1e-41e-5

How to run

With simpleFoamExtracted built and the case directory set up, the full run sequence is:

cd myCase
blockMesh

blockMesh reads system/blockMeshDict and writes the mesh to constant/polyMesh/. Check the final line — it should report the number of cells and zero errors.

simpleFoamExtracted 2>&1 | tee log.txt

Redirect both stdout and stderr into log.txt so residuals can be post-processed later. The tee command lets you watch progress in the terminal at the same time.

To run in parallel (requires MPI and a system/decomposeParDict):

decomposePar && mpirun -np 4 simpleFoamExtracted -parallel 2>&1 | tee log.txt

Post-processing in ParaView

Create an empty file named myCase.foam in the case directory, then open it with ParaView. The OpenFOAM reader will discover all time directories automatically.

touch myCase.foam && paraview myCase.foam
